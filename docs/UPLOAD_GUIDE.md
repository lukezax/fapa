# 微信小程序上传指引（自己手机上看开发版）

> 目标：把本项目跑起来，让 **你自己** 的手机微信能打开这个小程序（开发版 / 体验版）。
> 适用于还没有正式发布、不做审核的场景。认证、类目等资质工作不涉及。

---

## 0. 你需要准备

| 项 | 说明 |
|---|---|
| 微信小程序 AppID | 到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序后，在「设置 → 账号信息」里复制 |
| 微信开发者工具 | 官网下载 Windows / Mac 版：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html> |
| 一台手机 + 微信 | 扫码预览用 |

注册时选「个人主体」即可免费注册、直接可用（无需企业认证），云开发和个人主体兼容。

---

## 1. 替换两个配置（必做，否则无法上传）

### 1.1 AppID

编辑 `project.config.json`，把第 41 行的游客 AppID 换成你的真实 AppID：

```jsonc
"appid": "touristappid",   // ← 改成 "wx1234567890abcdef"
```

> 游客模式（touristappid）只能本地预览，**不能**上传代码、**不能**真机预览。必须换成真实 AppID。

### 1.2 云开发环境 ID

编辑 `miniprogram/app.js` 第 4 行，把占位环境 ID 换成你在第 3 步创建的环境 ID：

```js
globalData: {
  env: 'cloud1-xxxxx',   // ← 改成你创建的环境 ID，如 'jingpai-1g2h3j4k'
```

> 云函数内部用的是 `DYNAMIC_CURRENT_ENV`（跟随当前环境），所以只需要改这一处。

---

## 2. 导入项目到开发者工具

1. 打开微信开发者工具 → 登录（用注册小程序的微信扫码）
2. 「导入项目」
   - 目录：选择本项目根目录（`/home/lima/workspace/fapa`）
   - AppID：会自动读取 `project.config.json`（应已是你的真实 AppID）
   - 点击「确定」

> 若之前用游客模式打开过，先「详情 → 基本信息 → AppID」改成真实 AppID 再重新编译。

---

## 3. 开通云开发并创建环境

小程序所有数据都走云函数 + 云数据库，必须开通云开发：

1. 开发者工具顶部工具栏点「云开发」按钮（云朵图标）
2. 首次会提示开通 → 创建环境
   - 环境名称随意，如 `jingpai`（生成的 ID 形如 `jingpai-1g2h3j4k`）
   - 建议选**按量付费/免费额度**即可（本项目查询量小，免费额度够用）
3. 创建完成后，把环境 ID 填回 `app.js`（第 1.2 步）

---

## 4. 建集合 + 导入数据

云开发控制台（开发者工具「云开发」按钮内）→ 数据库：

| 步骤 | 操作 |
|---|---|
| 1. 创建集合 | 依次创建 5 个集合：`pool_all`、`cars`、`winners`、`favorites`、`histories` |
| 2. 导入数据 | 每个集合点「导入」，选择 `downloads/export/` 下对应 **`.json`** 文件（不是 `.jsonl`），格式选 **JSON** |

> **为什么是 `.json` 不是 `.jsonl`？** 控制台文件选择器只认 `.csv` / `.json` 扩展名，选 `.jsonl` 会提示「只支持 csv json」。内容本身没问题——微信云的 JSON 导入格式就是 JSON Lines（每行一个对象，`\n` 分隔）。项目里已生成 `.json` 副本（与 `.jsonl` 内容一致），直接用即可。

对应关系：

| 集合 | 导入文件 |
|---|---|
| `pool_all` | `downloads/export/pool_all.json`（约 20 万行，导入耗时较长，耐心等） |
| `cars` | `downloads/export/cars.json` |
| `winners` | `downloads/export/winners.json` |
| `favorites` / `histories` | 空集合即可，无需导入（运行时写入） |

**建索引**（pool_all 数据量大，不建索引排名查询会慢）：

数据库 → `pool_all` → 「索引管理」→ 新建两个复合索引：
- `zcid`（升序）+ `times`（升序）
- `zcid`（升序）+ `times`（升序）+ `reg_time`（升序）

**集合权限建议**：所有读写都经过云函数（云函数持有管理员权限，不受集合权限限制），所以把 5 个集合权限都设为「所有用户不可读写」最安全；若后续前端要直连读，再改成「所有用户可读」。

## 5. 上传部署云函数

开发者工具左侧资源管理器展开 `cloudfunctions/`，**对每个子目录**依次操作：

1. 右键云函数目录（如 `rank`）→ **「上传并部署：云端安装依赖」**
2. 等待「上传成功」提示

需要部署的 6 个云函数：`login`、`favorites`、`histories`、`rank`、`cars`、`trends`

> 一定要选「云端安装依赖」，它会在云端自动 `npm install wx-server-sdk`。
> 首次部署较慢（云端装依赖），属正常现象。

验证：云开发控制台 → 云函数 → 能看到 6 个函数，点「测试」→ 输入 `{"method": "calculate", "times": 50, "reg_time": "2014-05-10 21:42:36.576"}`，应返回 rank 等数据。

## 6. 在自己手机上看（两条路）

### 方式 A：真机预览（最快，推荐先用这个）

1. 开发者工具点工具栏「**预览**」按钮
2. 生成二维码 → 手机微信扫码
3. 手机上即打开 **开发版** 小程序

特点：
- 实时预览当前代码，改完代码重新点预览即可
- 开发版只适合开发调试，有效期短（二维码过期后重新生成）
- 打开后可在手机微信「最近使用的小程序」里再次进入

### 方式 B：上传为体验版（更接近正式形态，可长期用）

1. 开发者工具点工具栏「**上传**」
   - 版本号：填 `0.1.0`（可随意）
   - 项目备注：如 `首次体验版`
2. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)（用小程序管理员微信扫码登录）
3. 「管理 → 版本管理」→「开发版本」标签页 → 找到刚上传的版本 → 点「**选为体验版**」
4. 页面顶部会出现**体验版二维码**，手机微信扫码即打开
5. （可选）「管理 → 成员管理 → 体验成员」添加手机号，添加后该成员也能打开体验版

特点：
- 体验版长期有效，适合发给同事/朋友试用（体验成员上限约 15 人）
- 体验版同样**不需要审核**
- 开发版每次上传会保留历史版本，最新一个就是当前开发版

> **什么时候需要审核？** 只有点「提交审核 → 发布」成为线上正式版才需要。自己看开发版/体验版全程不需要。

## 7. 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 上传按钮置灰 / 提示无权限 | AppID 还是游客模式，或未用管理员微信登录开发者工具（见第 1.1 步） |
| 扫码打开是空白 / 报错 | 大概率云环境未通：检查 `app.js` 的 env ID 是否填对（第 1.2 步）、云函数是否部署（第 5 步） |
| 云函数测试报 `env 不存在`（`[100003] Env Not Exists`） | 环境 ID 写错，或云开发环境未创建（第 3 步）。报错括号里的 ID 若与你填的不一致，是 SDK 在无可用环境时的 fallback，仍以「创建环境 + 填对 ID」为准 |
| 导入数据报 `No available bucket. Please create a bucket in Storage.` | 环境缺存储桶：导入时文件要先传「存储」中转。到云开发控制台「存储」页确认有桶；空白则等初始化 1-2 分钟刷新，或重开开发者工具；有桶后重试导入 |
| 导入时提示「只支持 csv json」 | 控制台文件选择器只认 `.csv` / `.json` 扩展名。用 `downloads/export/` 下的 **`.json`** 副本（内容即 JSONL，符合微信云 JSON 导入格式），不要选 `.jsonl` |
| 上传云函数报 `请在编辑器云函数根目录（cloudfunctionRoot）选择一个云环境` | `cloudfunctionRoot` 配置没问题，是编辑器未关联环境：左侧文件树**右键 `cloudfunctions` 根目录** →「选择当前环境」→ 选你的环境 ID 后再逐个上传。若右键无环境选项，先点「云开发」按钮打开控制台再关闭，同步环境列表后重试 |
| 排名页数据为空 | `pool_all` 未导入或索引未建（第 4 步）；云函数返回 `资格池为空` 即此问题 |
| 列表页数据为空 | `cars` 集合未导入 |
| 打开提示「该小程序暂未发布」 | 正常现象，开发版/体验版即如此；发布才需审核 |
| 扫码提示「无权限」 | 预览码失效或微信账号非开发者，改用方式 B 体验版 + 添加体验成员 |
| 手机预览请求很慢 | pool_all 导入未完成或索引缺失，到云开发控制台确认导入行数 = 12,972（2400 期） |
